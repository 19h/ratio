# Dashboard fonts

DM Mono and Martian Mono set the dashboard's type. The TrueType files are
embedded in the `ra` binary and served from `/fonts/`, so the dashboard does not
contact a font CDN. The adjacent OFL files reproduce each font's SIL Open Font
License.

Source CSS: `https://fonts.googleapis.com/css2?family=DM+Mono:wght@400;500&family=Martian+Mono:wght@400;500&display=swap`

License sources:

- `https://github.com/google/fonts/blob/main/ofl/dmmono/OFL.txt`
- `https://github.com/google/fonts/blob/main/ofl/martianmono/OFL.txt`
